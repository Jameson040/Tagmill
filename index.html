Tag tens of thousands of images locally.

Camie Tagger v2 runs entirely in your browser via multithreaded WASM — images never leave this machine.

  1. Open a folder of images (or pick files).
  2. Download a model variant once (cached for future sessions).
  3. Start tagging — pause/resume any time; progress is saved locally.
  4. Search & organize by tags, then export JSON/CSV or rename/move files.

Built for 1k–50k+ image collections. Thumbnails & metadata are streamed, the full-resolution images are never all held in memory.
